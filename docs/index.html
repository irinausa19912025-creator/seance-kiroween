☾ Séance — one rule, three implementations, one equivalence report

A trading rule is written once, as data. Séance emits it as a Python reference, an MQL5 expert and a TradingView Pine v6 indicator, then compares the event streams candle by candle. On the synthetic example shipped here, Python and MQL5 matched on all 618 events; Pine was checked by hand, by event counts. The report is the product.

What this page proves, and what it does not

  • Proved here, live: the Python implementation generated from the rule above, run on these candles in your browser.
  • Recorded, not re-run here: the MQL5 side. MetaTrader 5 does not run in a browser, so the event stream of the real terminal run is shipped as a file and compared against.
  • Checked by hand, once: Pine. TradingView runs Pine only on its own platform, so the emitted Pine was compiled there and its counters read manually.
  • Not claimed: that any two implementations of any rule agree, or that the rule is profitable. The candles are synthetic and carry no market data.
